# 🗺️ Cross-Course Project 2: Networked Pathfinding & Graph Routing Visualizer

**Integrated Disciplines:**
- `CS213` Algorithms (Dijkstra, A*, Heuristic Search)
- `CS201` Discrete Structures (Adjacency Matrices & Graph Topologies)
- `CS331` Computer Networks (Client-Server Payload Routing & Metrics)
- `CS313` Web Programming (JSON API Contracts & Visual Graph Representation)

---

## 📌 Problem & Overview
Campus routing, distributed packet flow, and automated course prerequisite traversal all share a core foundation: graph topology navigation.

This project delivers a multi-algorithm shortest-path calculation and simulation engine that models weighted network topologies and outputs stepwise execution traces for visualization tools.
