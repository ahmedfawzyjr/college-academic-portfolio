## 📅 Semester-by-Semester Deep Dive

### 🟢 Year 1: Foundational Sciences & Programming Primitives (32 Credits)
- **Semester 1 (16 Credits)**:
  - `CS101` Introduction to Computer (3 Cr) — Binary systems, OS architecture, CLI commands.
  - `CS112` Java Programming (3 Cr) — Structured methods, conditionals, loops, array manipulation.
  - `HU101` Technical English 1 (2 Cr) — Computing terminology, technical reading, and writing.
  - `HU104` Principles of Management (2 Cr) — Organizational theory, planning, and control.
  - `MA101` Mathematics 1 (3 Cr) — Differential and integral calculus, series.
  - `PH101` General Physics (3 Cr) — Electrostatics, electric circuits, magnetic fields.
- **Semester 2 (16 Credits)**:
  - `CS111` Programming Language 1 (C++) (3 Cr) — Memory pointers, memory layout, file streams.
  - `EL101` Computer Electronics (3 Cr) — Diodes, BJT/FET transistors, logic gate circuits.
  - `HU102` Technical English 2 (2 Cr) — Technical presentation, business correspondence.
  - `HU103` Principles of Economics (2 Cr) — Microeconomics, market elasticity, software business models.
  - `IS101` Information Systems Fundamentals (3 Cr) — Data flows, ERP/CRM architecture, enterprise IS.
  - `ST101` Probability & Statistics (3 Cr) — Discrete/continuous probability distributions, hypothesis testing.

---

### 🔵 Year 2: Core Computer Science & Systems Hardware (31 Credits)
- **Semester 3 (17 Credits)**:
  - `CS201` Discrete Structures (3 Cr) — Logic, set theory, combinatorics, relations, graph models.
  - `CS211` Data Structures (3 Cr) — Abstract data types, linked lists, stacks, queues, BST, AVL trees.
  - `CS212` Programming Language 2 (OOP) (3 Cr) — Encapsulation, inheritance, polymorphism, templates, STL.
  - `CS221` Digital Logic Design (3 Cr) — K-Maps, combinational adders/multiplexers, sequential flip-flops, FSMs.
  - `HU202` Business Law & Ethics (2 Cr) — Cyber law, IP protection, open-source licensing, GDPR.
  - `MA202` Mathematics 2 (Linear Algebra) (3 Cr) — Matrix theory, eigenvalues, vector spaces, SVD.
- **Semester 4 (14 Credits)**:
  - `CS213` Design & Analysis of Algorithms (3 Cr) — Divide-and-conquer, greedy, dynamic programming, graph traversal.
  - `CS214` Visual Programming (C#) (3 Cr) — Windows Forms, event-driven programming, ADO.NET, LINQ.
  - `CS222` Computer Architecture & Organization (3 Cr) — MIPS assembly, datapath, pipelining, cache hierarchies.
  - `HU201` Principles of Accounting (2 Cr) — Double-entry bookkeeping, balance sheets, cash flow models.
  - `IS211` Database Systems 1 (3 Cr) — ER modeling, relational algebra, SQL DDL/DML, 1NF to BCNF normalization.

---

### 🟡 Year 3: Systems Software & Advanced Specializations (41 Credits)
- **Semester 5 (20 Credits)**:
  - `CS311` Automata & Formal Languages (3 Cr) — DFAs, NFAs, regular expressions, CFGs, Turing machines.
  - `CS313` Web Programming (3 Cr) — HTML5 semantic markup, CSS3 layouts, modern JavaScript, async fetch API.
  - `CS314` Python Programming (3 Cr) — Scripting, object-oriented Python, file processing, data pipelines.
  - `CS331` Computer Networks 1 (3 Cr) — OSI/TCP models, socket programming, HTTP/DNS, routing algorithms.
  - `CSC312` System Programming (3 Cr) — Two-pass assemblers, linkers/loaders, Unix process APIs (fork, exec, pipes).
  - `IS321` Project Management (2 Cr) — Agile/Scrum, WBS, CPM/PERT scheduling, risk estimation.
  - `MA301` Operations Research (3 Cr) — Linear programming, simplex method, transportation, network optimization.
- **Semester 6 (21 Credits)**:
  - `CS321` Operating Systems (3 Cr) — CPU scheduling, semaphores/mutexes, memory paging, page replacement.
  - `CS341` Computer Graphics (3 Cr) — OpenGL, rasterization, Cohen-Sutherland clipping, 3D affine transforms.
  - `HU301` Technical Report Writing (2 Cr) — Formal engineering reports, IEEE documentation format.
  - `HU302` Principles of Marketing (2 Cr) — Customer acquisition, 4Ps mix, digital conversion funnels.
  - `IS312` Database Systems 2 (3 Cr) — ACID transactions, lock protocols, PL/pgSQL stored procedures, NoSQL.
  - `IS331` System Analysis & Design (3 Cr) — Use cases, DFDs, UML sequence/class diagrams, architectural specs.
  - `MA302` Mathematics 3 (Diff Equations) (3 Cr) — ODEs, Laplace transforms, Fourier series, numerical solvers.
  - `TR301` Microsoft Office Skills Training (2 Cr) — Advanced Excel models, data visualization, reporting automation.

---

### 🟣 Year 4: Artificial Intelligence, Security & Capstone (38 Credits)
- **Semester 7 (15 Credits + 3 Cr Capstone Phase 1)**:
  - `CS441` Artificial Intelligence (3 Cr) — Search algorithms (A*, Minimax), CSP, heuristic evaluation.
  - `CS451` Information Security (3 Cr) — AES symmetric encryption, RSA public-key, SHA hashing, PKI/TLS.
  - `CS491` Special Topics in Computer Science (3 Cr) — Cloud computing, microservices architecture, Docker.
  - `CSC465` Software Engineering (3 Cr) — Software lifecycle, design patterns, clean code, TDD pipelines.
  - `CSC466` Data Mining (3 Cr) — Preprocessing, Apriori association rules, K-Means, classification models.
- **Semester 8 (17 Credits + 3 Cr Capstone Phase 2)**:
  - `CS415` Mobile Application Development (3 Cr) — Dart, Flutter reactive UI, state management, REST consumption.
  - `CS444` Digital Image Processing 1 (3 Cr) — Spatial filtering, histogram equalization, edge detection.
  - `CS445` Digital Image Processing 2 (3 Cr) — 2D Fourier transforms, Otsu segmentation, morphological filters.
  - `CSC465-ML` Machine Learning (3 Cr) — Supervised regression/classification, SVMs, Random Forests, MLP neural nets.
  - `EE242` Logic Design (Self Study) (3 Cr) — Quine-McCluskey minimization, asynchronous sequential circuits.
  - `HU401` Creative Thinking & Innovation (2 Cr) — SCAMPER brainstorming, TRIZ innovation, Design Thinking.
- **Continuous Capstone (6 Credits Total)**:
  - `CS499` Graduation Project — **iLearn Smart Educational Platform**: Full-stack cross-platform ecosystem.
