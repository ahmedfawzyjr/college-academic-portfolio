# CS112: Java Programming (برمجة جافا / برمجة هيكلية)

**Course Code:** `CS112`  
**Academic Term:** Y1S1 (Year 1, Semester 1)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Core CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Java Programming is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Java Fundamentals & Primitive Types, Control Statements & Loops, Methods & Parameter Passing. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Credit Card & Financial Transaction Validation Engine**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** None (Direct Entry)
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Java Fundamentals & Primitive Types.
- Implement verifiable algorithms and architectures utilizing Java 11+, JUnit 5, Maven.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Credit Card & Financial Transaction Validation Engine**.

---

## 📚 Topics
1. **Java Fundamentals & Primitive Types**
2. **Control Statements & Loops**
3. **Methods & Parameter Passing**
4. **Arrays & Multi-dimensional Arrays**
5. **Object-Oriented Basics & Encapsulation**
6. **Mathematical & String Algorithms**
