# CS451: Information Security (أمن المعلومات وشبكاتها)

**Course Code:** `CS451`  
**Academic Term:** Y4S1 (Year 4, Semester 7)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Security  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Information Security is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Security Principles: Confidentiality, Integrity, Availability (CIA), Classical Ciphers & Cryptanalysis, Symmetric Key Cryptography (DES, 3DES, AES). The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Cryptographic Suite & Secure Communication Engine**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS331`, `CS201`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Security Principles: Confidentiality, Integrity, Availability (CIA).
- Implement verifiable algorithms and architectures utilizing Python, Cryptography library, OpenSSL.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Cryptographic Suite & Secure Communication Engine**.

---

## 📚 Topics
1. **Security Principles: Confidentiality, Integrity, Availability (CIA)**
2. **Classical Ciphers & Cryptanalysis**
3. **Symmetric Key Cryptography (DES, 3DES, AES)**
4. **Asymmetric Cryptography (RSA, Diffie-Hellman)**
5. **Cryptographic Hash Functions (SHA-256) & HMAC**
6. **Digital Signatures, Public Key Infrastructure (PKI) & SSL/TLS**
