# Measurable Learning Outcomes: CS451 — Information Security

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of Security Principles: Confidentiality, Integrity, Availability (CIA) and Classical Ciphers & Cryptanalysis.
2. **Design and Implement**: Build, debug, and document working engineering implementations of Cryptographic Suite & Secure Communication Engine.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Information Security to modern software engineering workflows and architectural design patterns.
