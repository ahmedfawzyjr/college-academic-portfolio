# CS101: Introduction to Computer (مقدمة في الحاسب الآلي)

**Course Code:** `CS101`  
**Academic Term:** Y1S1 (Year 1, Semester 1)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Core CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Introduction to Computer is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Computer Hardware & Architecture Fundamentals, Number Systems & Binary Logic, Operating Systems Overview. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **System Information & Resource Inspector CLI**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** None (Direct Entry)
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Computer Hardware & Architecture Fundamentals.
- Implement verifiable algorithms and architectures utilizing CLI, PowerShell, Linux Basics, Hardware Diagnostics.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **System Information & Resource Inspector CLI**.

---

## 📚 Topics
1. **Computer Hardware & Architecture Fundamentals**
2. **Number Systems & Binary Logic**
3. **Operating Systems Overview**
4. **Networks & The Internet**
5. **Information Security & Privacy Basics**
6. **Software Types & File Systems**
