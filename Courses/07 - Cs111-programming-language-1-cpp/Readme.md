# CS111: Programming Language 1 (C++) (لغات برمجة 1 (C++))

**Course Code:** `CS111`  
**Academic Term:** Y1S2 (Year 1, Semester 2)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Core CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Programming Language 1 (C++) is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in C++ Syntax & Compilers, Control Structures & Loops, Functions & Scope. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Personal Expense Tracker & Financial CLI**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS101`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of C++ Syntax & Compilers.
- Implement verifiable algorithms and architectures utilizing C++17, GCC / Clang, Make / CMake.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Personal Expense Tracker & Financial CLI**.

---

## 📚 Topics
1. **C++ Syntax & Compilers**
2. **Control Structures & Loops**
3. **Functions & Scope**
4. **Pointers & Memory Addressing**
5. **Arrays & C-Strings**
6. **File I/O Streams & Structs**
