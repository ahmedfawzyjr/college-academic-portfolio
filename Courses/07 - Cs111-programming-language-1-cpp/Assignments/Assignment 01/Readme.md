# Assignment 01: Temperature & Unit Conversion CLI

## Objective
Implement a console application in C++ that converts temperatures between Celsius, Fahrenheit, and Kelvin, and calculates body mass index (BMI).

## Requirements
1. Prompt user for conversion type via interactive menu.
2. Handle floating-point inputs accurately.
3. Validate user input for invalid selection or sub-zero Kelvin values.

## Expected Output
```text
Select Option: 1 (Celsius to Fahrenheit)
Enter temperature in Celsius: 25
Result: 77.0 °F
```
