# Measurable Learning Outcomes: CS111 — Programming Language 1 (C++)

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of C++ Syntax & Compilers and Control Structures & Loops.
2. **Design and Implement**: Build, debug, and document working engineering implementations of Personal Expense Tracker & Financial CLI.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Programming Language 1 (C++) to modern software engineering workflows and architectural design patterns.
