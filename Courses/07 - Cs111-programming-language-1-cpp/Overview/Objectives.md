# Course Objectives: CS111 — Programming Language 1 (C++)

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in programming language 1 (c++).

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in C++ Syntax & Compilers and Control Structures & Loops.
2. **Applied Implementation**: Develop verified practical solutions using C++17, GCC / Clang, Make / CMake.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across File I/O Streams & Structs.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
