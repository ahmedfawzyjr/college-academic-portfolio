# CS441: Artificial Intelligence (الذكاء الاصطناعي)

**Course Code:** `CS441`  
**Academic Term:** Y4S1 (Year 4, Semester 7)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** AI & Data  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Artificial Intelligence is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Intelligent Agents & Environment Types, Uninformed Search (BFS, DFS, Uniform Cost Search), Informed / Heuristic Search (A*, Greedy Best-First). The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **A* Pathfinding & Minimax Adversarial Game Engine**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS213`, `CS201`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Intelligent Agents & Environment Types.
- Implement verifiable algorithms and architectures utilizing Python 3, Pytest, NumPy.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **A* Pathfinding & Minimax Adversarial Game Engine**.

---

## 📚 Topics
1. **Intelligent Agents & Environment Types**
2. **Uninformed Search (BFS, DFS, Uniform Cost Search)**
3. **Informed / Heuristic Search (A*, Greedy Best-First)**
4. **Adversarial Search & Game Playing (Minimax, Alpha-Beta Pruning)**
5. **Constraint Satisfaction Problems (CSP)**
6. **Knowledge Representation & First-Order Logic Inference**
