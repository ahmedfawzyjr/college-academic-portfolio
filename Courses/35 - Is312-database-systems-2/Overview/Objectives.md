# Course Objectives: IS312 — Database Systems 2

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in database systems 2.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Transaction Processing & ACID Properties and Concurrency Control (Locking, Timestamping, 2PL).
2. **Applied Implementation**: Develop verified practical solutions using PostgreSQL, PL/pgSQL, Redis.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across NoSQL Databases & Distributed Data Systems.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
