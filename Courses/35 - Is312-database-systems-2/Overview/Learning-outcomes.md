# Measurable Learning Outcomes: IS312 — Database Systems 2

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of Transaction Processing & ACID Properties and Concurrency Control (Locking, Timestamping, 2PL).
2. **Design and Implement**: Build, debug, and document working engineering implementations of ACID Transaction & High-Concurrency Banking Database Engine.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Database Systems 2 to modern software engineering workflows and architectural design patterns.
