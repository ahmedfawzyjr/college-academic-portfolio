# CSC466: Data Mining (تنقيب البيانات)

**Course Code:** `CSC466`  
**Academic Term:** Y4S1 (Year 4, Semester 7)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** AI & Data  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Data Mining is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Data Mining Process & CRISP-DM Methodology, Data Preprocessing: Cleaning, Integration, Transformation, Reduction, Association Rule Mining & Apriori Algorithm. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Apriori Association Rule & K-Means Clustering Mining Pipeline**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `IS211`, `ST101`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Data Mining Process & CRISP-DM Methodology.
- Implement verifiable algorithms and architectures utilizing Python, Scikit-Learn, Pandas, Matplotlib.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Apriori Association Rule & K-Means Clustering Mining Pipeline**.

---

## 📚 Topics
1. **Data Mining Process & CRISP-DM Methodology**
2. **Data Preprocessing: Cleaning, Integration, Transformation, Reduction**
3. **Association Rule Mining & Apriori Algorithm**
4. **Classification Algorithms (Decision Trees, Naive Bayes, k-NN)**
5. **Clustering Algorithms (K-Means, Hierarchical Clustering, DBSCAN)**
6. **Model Evaluation: Confusion Matrix, ROC-AUC, Cross-Validation**
