# Measurable Learning Outcomes: CS222 — Computer Architecture & Organization

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of Instruction Set Architecture (ISA) & MIPS Assembly and Processor Datapath & Control Units.
2. **Design and Implement**: Build, debug, and document working engineering implementations of MIPS Instruction Set CPU Emulator & Cache Simulator.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Computer Architecture & Organization to modern software engineering workflows and architectural design patterns.
