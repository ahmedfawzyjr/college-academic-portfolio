# CS331: Computer Networks 1 (شبكات الحاسب 1)

**Course Code:** `CS331`  
**Academic Term:** Y3S1 (Year 3, Semester 5)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Infrastructure  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Computer Networks 1 is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in OSI 7-Layer & TCP/IP 4-Layer Models, Application Layer: HTTP, DNS, SMTP, FTP, Transport Layer: TCP (Reliable Data Transfer, Congestion Control) & UDP. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Concurrent Multi-Client Server Messaging System**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS101`, `CS222`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of OSI 7-Layer & TCP/IP 4-Layer Models.
- Implement verifiable algorithms and architectures utilizing Python Sockets, Wireshark, Packet Tracer.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Concurrent Multi-Client Server Messaging System**.

---

## 📚 Topics
1. **OSI 7-Layer & TCP/IP 4-Layer Models**
2. **Application Layer: HTTP, DNS, SMTP, FTP**
3. **Transport Layer: TCP (Reliable Data Transfer, Congestion Control) & UDP**
4. **Network Layer: IP Addressing, Subnetting, Routing Algorithms**
5. **Link Layer: Ethernet, MAC Addressing & ARP**
6. **Socket Programming Fundamentals**
