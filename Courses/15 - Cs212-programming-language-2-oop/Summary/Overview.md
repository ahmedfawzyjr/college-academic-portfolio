# Executive Overview: CS212 - Programming Language II (OOP)

## Course Summary
- **Course Name:** Programming Language II (OOP) (لغات برمجة 2 (OOP))
- **Code:** `CS212`
- **Credit Hours:** 3 Credit Hours
- **Level:** 2nd Year - Term 1

## Key Learning Outcomes
1. Master core theoretical principles and foundational concepts of Programming Language II (OOP).
2. Apply practical algorithms, tools, and methodologies in solving real-world problems.
3. Complete structured lab exercises, code examples, and assignment implementations.
