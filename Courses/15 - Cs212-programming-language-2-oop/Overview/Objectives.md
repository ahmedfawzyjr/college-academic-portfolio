# Course Objectives: CS212 — Programming Language 2 (OOP)

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in programming language 2 (oop).

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Classes, Objects, Constructors & Destructors and Operator Overloading & Friend Functions.
2. **Applied Implementation**: Develop verified practical solutions using C++17, UML, Valgrind.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Exception Handling & Stream Formatting.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
