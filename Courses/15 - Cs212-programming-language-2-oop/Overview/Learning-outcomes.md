# Measurable Learning Outcomes: CS212 — Programming Language 2 (OOP)

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of Classes, Objects, Constructors & Destructors and Operator Overloading & Friend Functions.
2. **Design and Implement**: Build, debug, and document working engineering implementations of Object-Oriented University Library Management System.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Programming Language 2 (OOP) to modern software engineering workflows and architectural design patterns.
