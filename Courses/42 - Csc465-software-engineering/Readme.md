# CSC465: Software Engineering (هندسة البرمجيات)

**Course Code:** `CSC465`  
**Academic Term:** Y4S1 (Year 4, Semester 7)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Software Dev  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Software Engineering is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Software Processes & Agile Methodologies, Requirements Engineering & IEEE 830 SRS Specification, System Architectural Styles (Layered, Microservices, Event-Driven). The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Production-Grade Academic Service Architecture & TDD Suite**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `IS331`, `CS212`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Software Processes & Agile Methodologies.
- Implement verifiable algorithms and architectures utilizing UML, FastAPI / Python, Pytest, Clean Code Architecture.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Production-Grade Academic Service Architecture & TDD Suite**.

---

## 📚 Topics
1. **Software Processes & Agile Methodologies**
2. **Requirements Engineering & IEEE 830 SRS Specification**
3. **System Architectural Styles (Layered, Microservices, Event-Driven)**
4. **Software Design Patterns (GoF: Creational, Structural, Behavioral)**
5. **Software Testing Strategies (Unit, Integration, TDD, CI/CD)**
6. **Software Maintenance, Refactoring & Clean Code Practices**
