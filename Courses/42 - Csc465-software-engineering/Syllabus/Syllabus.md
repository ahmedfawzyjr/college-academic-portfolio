# Course Syllabus: CSC465 — Software Engineering

**Department:** Computer Science Department  
**Academic Term:** Y4S1 (Year 4, Semester 7)  
**Credit Hours:** 3 Credit Hours  
**Instruction Format:** Lectures (Sessions), Practical Laboratory Exercises, Graded Assignments  

---

## 📅 Weekly Topic Distribution
- **Week 1**: Software Processes & Agile Methodologies
- **Week 2**: Requirements Engineering & IEEE 830 SRS Specification
- **Week 3**: System Architectural Styles (Layered, Microservices, Event-Driven)
- **Week 4**: Software Design Patterns (GoF: Creational, Structural, Behavioral)
- **Week 5**: Software Testing Strategies (Unit, Integration, TDD, CI/CD)
- **Week 6**: Software Maintenance, Refactoring & Clean Code Practices

---

## 📊 Assessment & Grading Matrix
- **Midterm Examination:** 20%
- **Practical Laboratory & Quizzes:** 20%
- **Assignments & Course Engineering Project:** 20%
- **Final Comprehensive Examination:** 40%
- **Total:** 100%
