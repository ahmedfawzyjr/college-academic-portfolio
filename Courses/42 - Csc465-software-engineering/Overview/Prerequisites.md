# Prerequisites & Academic Chain: CSC465 — Software Engineering

## Strict Prerequisites
- **Formal Requirements**: `IS331`, `CS212`

## Foundational Knowledge Requirements
Before engaging with the topics in Software Engineering, students are expected to possess:
- Familiarity with core computational thinking and problem decomposition.
- Solid grounding in the prerequisite concepts: IS331, CS212.

## Downstream Course Chain
Successful completion of `CSC465` serves as a prerequisite for subsequent advanced coursework in the curriculum:
- Enhances competency in upper-division systems and applications.
- Directly supports the Graduation Project (`CS499`).
