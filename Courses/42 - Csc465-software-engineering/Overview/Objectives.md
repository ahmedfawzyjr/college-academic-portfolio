# Course Objectives: CSC465 — Software Engineering

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in software engineering.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Software Processes & Agile Methodologies and Requirements Engineering & IEEE 830 SRS Specification.
2. **Applied Implementation**: Develop verified practical solutions using UML, FastAPI / Python, Pytest.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Software Maintenance, Refactoring & Clean Code Practices.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
