# Technical Note: Data Visualization & Dashboard Design

## 1. Conceptual Framework
Data Visualization & Dashboard Design forms a foundational pillar in Microsoft Office Skills Training. It establishes the abstractions required for scalable computational design.

## 2. Engineering Tradeoffs & Design Principles
