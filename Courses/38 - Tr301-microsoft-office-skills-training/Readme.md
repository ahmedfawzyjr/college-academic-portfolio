# TR301: Microsoft Office Skills Training (تدريب مهارات مكتبية)

**Course Code:** `TR301`  
**Academic Term:** Y3S2 (Year 3, Semester 6)  
**Credit Hours:** 2 Credit Hours  
**Curriculum Category:** Skills  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Microsoft Office Skills Training is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Advanced Excel (VLOOKUP, INDEX/MATCH, Pivot Tables, Macros), Data Visualization & Dashboard Design, Word for Technical Manuscripts & Automation. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Automated Financial & Academic Reporting Dashboard**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS101`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Advanced Excel (VLOOKUP, INDEX/MATCH, Pivot Tables, Macros).
- Implement verifiable algorithms and architectures utilizing Excel, VBA, Python openpyxl, PowerBI.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Automated Financial & Academic Reporting Dashboard**.

---

## 📚 Topics
1. **Advanced Excel (VLOOKUP, INDEX/MATCH, Pivot Tables, Macros)**
2. **Data Visualization & Dashboard Design**
3. **Word for Technical Manuscripts & Automation**
4. **PowerPoint for Technical Defense & Visual Narratives**
5. **Access Relational Desktop Database Management**
6. **Office Automation with Python / VBA**
