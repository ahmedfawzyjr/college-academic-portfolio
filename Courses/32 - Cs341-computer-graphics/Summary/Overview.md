# Executive Overview: CS341 - Computer Graphics

## Course Summary
- **Course Name:** Computer Graphics (رسومات الحاسب)
- **Code:** `CS341`
- **Credit Hours:** 3 Credit Hours
- **Level:** 3rd Year - Term 2

## Key Learning Outcomes
1. Master core theoretical principles and foundational concepts of Computer Graphics.
2. Apply practical algorithms, tools, and methodologies in solving real-world problems.
3. Complete structured lab exercises, code examples, and assignment implementations.
