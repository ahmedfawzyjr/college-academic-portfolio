# CS341: Computer Graphics (رسومات الحاسب)

**Course Code:** `CS341`  
**Academic Term:** Y3S2 (Year 3, Semester 6)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Applied CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Computer Graphics is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Graphics Pipeline & Rasterization, Line Drawing Algorithms (DDA, Bresenham), Circle Generation Algorithms (Midpoint). The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **2D/3D Rasterization Engine & Transformation Suite**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS111`, `MA202`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Graphics Pipeline & Rasterization.
- Implement verifiable algorithms and architectures utilizing C++, OpenGL / GLUT, GLM, Python.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **2D/3D Rasterization Engine & Transformation Suite**.

---

## 📚 Topics
1. **Graphics Pipeline & Rasterization**
2. **Line Drawing Algorithms (DDA, Bresenham)**
3. **Circle Generation Algorithms (Midpoint)**
4. **2D & 3D Geometric Transformations (Translation, Rotation, Scaling)**
5. **Viewing, Projection & Clipping (Cohen-Sutherland)**
6. **Lighting, Shading Models & OpenGL Basics**
