# Measurable Learning Outcomes: CS341 — Computer Graphics

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of Graphics Pipeline & Rasterization and Line Drawing Algorithms (DDA, Bresenham).
2. **Design and Implement**: Build, debug, and document working engineering implementations of 2D/3D Rasterization Engine & Transformation Suite.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Computer Graphics to modern software engineering workflows and architectural design patterns.
