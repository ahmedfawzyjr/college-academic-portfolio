# Course Objectives: CS341 — Computer Graphics

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in computer graphics.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Graphics Pipeline & Rasterization and Line Drawing Algorithms (DDA, Bresenham).
2. **Applied Implementation**: Develop verified practical solutions using C++, OpenGL / GLUT, GLM.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Lighting, Shading Models & OpenGL Basics.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
