# Executive Overview: CS444 - Digital Image Processing I

## Course Summary
- **Course Name:** Digital Image Processing I (معالجة الصور الرقمية 1)
- **Code:** `CS444`
- **Credit Hours:** 3 Credit Hours
- **Level:** 4th Year - Term 2

## Key Learning Outcomes
1. Master core theoretical principles and foundational concepts of Digital Image Processing I.
2. Apply practical algorithms, tools, and methodologies in solving real-world problems.
3. Complete structured lab exercises, code examples, and assignment implementations.
