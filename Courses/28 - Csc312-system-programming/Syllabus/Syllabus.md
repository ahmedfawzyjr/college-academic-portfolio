# Course Syllabus: CSC312 — System Programming

**Department:** Computer Science Department  
**Academic Term:** Y3S1 (Year 3, Semester 5)  
**Credit Hours:** 3 Credit Hours  
**Instruction Format:** Lectures (Sessions), Practical Laboratory Exercises, Graded Assignments  

---

## 📅 Weekly Topic Distribution
- **Week 1**: Assemblers: Two-Pass Assembler Architecture
- **Week 2**: Loaders and Linkers: Relocating, Dynamic Linking
- **Week 3**: Macro Processors: Design & Expansion Algorithms
- **Week 4**: Compilers Overview: Lexical, Syntax, Code Generation
- **Week 5**: POSIX System Calls & Process Spawning (fork, exec, wait)
- **Week 6**: Inter-Process Communication (Pipes, Shared Memory, Signals)

---

## 📊 Assessment & Grading Matrix
- **Midterm Examination:** 20%
- **Practical Laboratory & Quizzes:** 20%
- **Assignments & Course Engineering Project:** 20%
- **Final Comprehensive Examination:** 40%
- **Total:** 100%
