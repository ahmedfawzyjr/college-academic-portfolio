# CSC312: System Programming (برمجة النظم)

**Course Code:** `CSC312`  
**Academic Term:** Y3S1 (Year 3, Semester 5)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Systems  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
System Programming is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Assemblers: Two-Pass Assembler Architecture, Loaders and Linkers: Relocating, Dynamic Linking, Macro Processors: Design & Expansion Algorithms. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Two-Pass Assembler & Unix Shell Implementation**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS111`, `CS222`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Assemblers: Two-Pass Assembler Architecture.
- Implement verifiable algorithms and architectures utilizing C, GCC, Linux POSIX APIs, GDB.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Two-Pass Assembler & Unix Shell Implementation**.

---

## 📚 Topics
1. **Assemblers: Two-Pass Assembler Architecture**
2. **Loaders and Linkers: Relocating, Dynamic Linking**
3. **Macro Processors: Design & Expansion Algorithms**
4. **Compilers Overview: Lexical, Syntax, Code Generation**
5. **POSIX System Calls & Process Spawning (fork, exec, wait)**
6. **Inter-Process Communication (Pipes, Shared Memory, Signals)**
