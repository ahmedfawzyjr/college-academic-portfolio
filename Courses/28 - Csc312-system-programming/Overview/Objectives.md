# Course Objectives: CSC312 — System Programming

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in system programming.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Assemblers: Two-Pass Assembler Architecture and Loaders and Linkers: Relocating, Dynamic Linking.
2. **Applied Implementation**: Develop verified practical solutions using C, GCC, Linux POSIX APIs.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Inter-Process Communication (Pipes, Shared Memory, Signals).
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
