# Measurable Learning Outcomes: CSC312 — System Programming

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of Assemblers: Two-Pass Assembler Architecture and Loaders and Linkers: Relocating, Dynamic Linking.
2. **Design and Implement**: Build, debug, and document working engineering implementations of Two-Pass Assembler & Unix Shell Implementation.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect System Programming to modern software engineering workflows and architectural design patterns.
