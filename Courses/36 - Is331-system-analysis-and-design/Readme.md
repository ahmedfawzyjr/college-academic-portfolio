# IS331: System Analysis & Design (تحليل وتصميم النظم)

**Course Code:** `IS331`  
**Academic Term:** Y3S2 (Year 3, Semester 6)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Software Dev  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
System Analysis & Design is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in SDLC Methodologies (Waterfall, Agile, Spiral), Requirements Determination & Use Case Modeling, Data Flow Diagrams (DFD Levels 0, 1, 2). The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Enterprise Academic Management System Analysis & UML Blueprint**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `IS101`, `IS211`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of SDLC Methodologies (Waterfall, Agile, Spiral).
- Implement verifiable algorithms and architectures utilizing PlantUML, Mermaid.js, Draw.io, Markdown.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Enterprise Academic Management System Analysis & UML Blueprint**.

---

## 📚 Topics
1. **SDLC Methodologies (Waterfall, Agile, Spiral)**
2. **Requirements Determination & Use Case Modeling**
3. **Data Flow Diagrams (DFD Levels 0, 1, 2)**
4. **UML Behavioral Diagrams (Sequence, Activity, State)**
5. **UML Structural Diagrams (Class, Component, Deployment)**
6. **System Architecture & Interface Design**
