# Course Objectives: IS331 — System Analysis & Design

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in system analysis & design.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in SDLC Methodologies (Waterfall, Agile, Spiral) and Requirements Determination & Use Case Modeling.
2. **Applied Implementation**: Develop verified practical solutions using PlantUML, Mermaid.js, Draw.io.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across System Architecture & Interface Design.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
