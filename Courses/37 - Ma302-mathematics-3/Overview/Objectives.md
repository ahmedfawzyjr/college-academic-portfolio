# Course Objectives: MA302 — Mathematics 3

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in mathematics 3.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in First-Order Differential Equations (Separable, Exact, Linear) and Second-Order Linear Homogeneous & Non-Homogeneous Equations.
2. **Applied Implementation**: Develop verified practical solutions using Python, SciPy, SymPy.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Numerical Methods for Differential Equations (Euler, Runge-Kutta).
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
