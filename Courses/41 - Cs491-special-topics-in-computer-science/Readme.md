# CS491: Special Topics in Computer Science (موضوعات خاصة في علوم الحاسب)

**Course Code:** `CS491`  
**Academic Term:** Y4S1 (Year 4, Semester 7)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Advanced CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Special Topics in Computer Science is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Cloud Computing Architecture (IaaS, PaaS, SaaS), Microservices Architecture & RESTful APIs, Containerization with Docker & Container Orchestration. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Containerized Microservices Architecture & CI/CD Pipeline**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS313`, `CS314`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Cloud Computing Architecture (IaaS, PaaS, SaaS).
- Implement verifiable algorithms and architectures utilizing Docker, FastAPI, GitHub Actions, Python.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Containerized Microservices Architecture & CI/CD Pipeline**.

---

## 📚 Topics
1. **Cloud Computing Architecture (IaaS, PaaS, SaaS)**
2. **Microservices Architecture & RESTful APIs**
3. **Containerization with Docker & Container Orchestration**
4. **Serverless Computing & Cloud Functions**
5. **DevOps Pipelines & Continuous Integration/Continuous Deployment**
6. **Edge Computing & Emerging Architectural Paradigms**
