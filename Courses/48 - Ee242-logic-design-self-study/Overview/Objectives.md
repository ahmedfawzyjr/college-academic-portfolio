# Course Objectives: EE242 — Logic Design (Self Study)

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in logic design (self study).

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Advanced Boolean Algebra & Minimization Algorithms (Quine-McCluskey) and Design of Complex Sequential Circuits & Registers.
2. **Applied Implementation**: Develop verified practical solutions using Verilog, Python Logic Synthesizer, Logisim.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Hazards in Digital Circuits & Glitch Prevention.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
