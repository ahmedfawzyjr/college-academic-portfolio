# Executive Overview: EL101 - Computer Electronics

## Course Summary
- **Course Name:** Computer Electronics (إلكترونيات حاسب)
- **Code:** `EL101`
- **Credit Hours:** 3 Credit Hours
- **Level:** 1st Year - Term 2

## Key Learning Outcomes
1. Master core theoretical principles and foundational concepts of Computer Electronics.
2. Apply practical algorithms, tools, and methodologies in solving real-world problems.
3. Complete structured lab exercises, code examples, and assignment implementations.
