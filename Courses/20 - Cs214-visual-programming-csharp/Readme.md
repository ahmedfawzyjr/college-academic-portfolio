# CS214: Visual Programming (C#) (البرمجة المرئية (C#))

**Course Code:** `CS214`  
**Academic Term:** Y2S2 (Year 2, Semester 4)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Applied CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Visual Programming (C#) is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in .NET Framework & CLR Architecture, C# Language Syntax, Properties & Delegates, Windows Forms & GUI Event-Driven Programming. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Desktop University Student & Grade Management System**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS212`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of .NET Framework & CLR Architecture.
- Implement verifiable algorithms and architectures utilizing C#, .NET Core / .NET 6+, Windows Forms / WPF.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Desktop University Student & Grade Management System**.

---

## 📚 Topics
1. **.NET Framework & CLR Architecture**
2. **C# Language Syntax, Properties & Delegates**
3. **Windows Forms & GUI Event-Driven Programming**
4. **Data Binding & ADO.NET / Entity Framework Basics**
5. **File Processing & LINQ Queries**
6. **Component Design & Multi-threading Basics**
