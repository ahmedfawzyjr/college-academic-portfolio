# Measurable Learning Outcomes: CS214 — Visual Programming (C#)

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of .NET Framework & CLR Architecture and C# Language Syntax, Properties & Delegates.
2. **Design and Implement**: Build, debug, and document working engineering implementations of Desktop University Student & Grade Management System.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Visual Programming (C#) to modern software engineering workflows and architectural design patterns.
