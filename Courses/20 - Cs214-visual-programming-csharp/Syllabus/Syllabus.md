# Course Syllabus: CS214 — Visual Programming (C#)

**Department:** Computer Science Department  
**Academic Term:** Y2S2 (Year 2, Semester 4)  
**Credit Hours:** 3 Credit Hours  
**Instruction Format:** Lectures (Sessions), Practical Laboratory Exercises, Graded Assignments  

---

## 📅 Weekly Topic Distribution
- **Week 1**: .NET Framework & CLR Architecture
- **Week 2**: C# Language Syntax, Properties & Delegates
- **Week 3**: Windows Forms & GUI Event-Driven Programming
- **Week 4**: Data Binding & ADO.NET / Entity Framework Basics
- **Week 5**: File Processing & LINQ Queries
- **Week 6**: Component Design & Multi-threading Basics

---

## 📊 Assessment & Grading Matrix
- **Midterm Examination:** 20%
- **Practical Laboratory & Quizzes:** 20%
- **Assignments & Course Engineering Project:** 20%
- **Final Comprehensive Examination:** 40%
- **Total:** 100%
