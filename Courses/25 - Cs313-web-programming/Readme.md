# CS313: Web Programming (برمجة الويب)

**Course Code:** `CS313`  
**Academic Term:** Y3S1 (Year 3, Semester 5)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Applied CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Web Programming is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in HTML5 Semantic Structure & Modern Standards, CSS3 Flexbox, Grid & Responsive Layouts, JavaScript DOM Manipulation & Event Handling. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Interactive Academic Web Portal & Student Dashboard**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS111`, `IS211`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of HTML5 Semantic Structure & Modern Standards.
- Implement verifiable algorithms and architectures utilizing HTML5, CSS3, JavaScript ES6+, Node.js.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Interactive Academic Web Portal & Student Dashboard**.

---

## 📚 Topics
1. **HTML5 Semantic Structure & Modern Standards**
2. **CSS3 Flexbox, Grid & Responsive Layouts**
3. **JavaScript DOM Manipulation & Event Handling**
4. **Asynchronous JS, Fetch API & JSON**
5. **RESTful Client-Server Interaction**
6. **Web Security Best Practices (XSS, CSRF prevention)**
