# Measurable Learning Outcomes: CSC465-ML — Machine Learning

By the conclusion of this course, students demonstrate the ability to:

1. **Explain and Formulate**: Articulate the theoretical principles of Machine Learning Paradigms: Supervised, Unsupervised, Reinforcement and Linear Regression, Gradient Descent & Regularization (Ridge, Lasso).
2. **Design and Implement**: Build, debug, and document working engineering implementations of End-to-End Machine Learning Model Training & Evaluation Pipeline.
3. **Evaluate and Optimize**: Evaluate algorithmic or system trade-offs using empirical benchmarks and theoretical bounds.
4. **Integrate**: Connect Machine Learning to modern software engineering workflows and architectural design patterns.
