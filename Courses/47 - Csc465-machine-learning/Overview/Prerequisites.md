# Prerequisites & Academic Chain: CSC465-ML — Machine Learning

## Strict Prerequisites
- **Formal Requirements**: `CS441`, `ST101`, `MA202`

## Foundational Knowledge Requirements
Before engaging with the topics in Machine Learning, students are expected to possess:
- Familiarity with core computational thinking and problem decomposition.
- Solid grounding in the prerequisite concepts: CS441, ST101, MA202.

## Downstream Course Chain
Successful completion of `CSC465-ML` serves as a prerequisite for subsequent advanced coursework in the curriculum:
- Enhances competency in upper-division systems and applications.
- Directly supports the Graduation Project (`CS499`).
