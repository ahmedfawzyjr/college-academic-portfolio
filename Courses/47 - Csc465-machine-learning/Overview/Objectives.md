# Course Objectives: CSC465-ML — Machine Learning

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in machine learning.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Machine Learning Paradigms: Supervised, Unsupervised, Reinforcement and Linear Regression, Gradient Descent & Regularization (Ridge, Lasso).
2. **Applied Implementation**: Develop verified practical solutions using Python, Scikit-Learn, PyTorch / TensorFlow.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Neural Networks Fundamentals: Perceptron, Multi-Layer Perceptrons (MLP).
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
