# CSC465-ML: Machine Learning (تعلم الآلة)

**Course Code:** `CSC465-ML`  
**Academic Term:** Y4S2 (Year 4, Semester 8)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** AI & Data  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Machine Learning is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Machine Learning Paradigms: Supervised, Unsupervised, Reinforcement, Linear Regression, Gradient Descent & Regularization (Ridge, Lasso), Logistic Regression & Binary/Multiclass Classification. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **End-to-End Machine Learning Model Training & Evaluation Pipeline**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS441`, `ST101`, `MA202`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Machine Learning Paradigms: Supervised, Unsupervised, Reinforcement.
- Implement verifiable algorithms and architectures utilizing Python, Scikit-Learn, PyTorch / TensorFlow, NumPy.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **End-to-End Machine Learning Model Training & Evaluation Pipeline**.

---

## 📚 Topics
1. **Machine Learning Paradigms: Supervised, Unsupervised, Reinforcement**
2. **Linear Regression, Gradient Descent & Regularization (Ridge, Lasso)**
3. **Logistic Regression & Binary/Multiclass Classification**
4. **Support Vector Machines (SVM) & Kernel Trick**
5. **Ensemble Learning: Random Forests, Boosting (AdaBoost, XGBoost)**
6. **Neural Networks Fundamentals: Perceptron, Multi-Layer Perceptrons (MLP)**
