# Course Objectives: IS321 — Project Management

## Primary Academic Objectives
The overarching educational goal of this course is to provide foundational and rigorous applied instruction in project management.

### Specific Objectives
1. **Theoretical Grounding**: Understand fundamental paradigms and mathematical/logical formulations in Project Life Cycle & Stakeholder Management and Scope Management & Work Breakdown Structure (WBS).
2. **Applied Implementation**: Develop verified practical solutions using Jira, MS Project, Trello.
3. **Engineering Analysis**: Analyze complexity, design trade-offs, and failure modes across Agile & Scrum Methodologies.
4. **Professional Competency**: Apply industry-standard documentation, testing, and clean code practices.
