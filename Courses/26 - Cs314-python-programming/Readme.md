# CS314: Python Programming (برمجة بلغة بايثون)

**Course Code:** `CS314`  
**Academic Term:** Y3S1 (Year 3, Semester 5)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Applied CS  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Python Programming is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Python Data Types, List Comprehensions & Dictionaries, Object-Oriented Python & Magic Methods, File Handling, JSON & CSV Processing. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Automated Data Processing & Web Scraping Pipeline**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS111`, `CS212`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Python Data Types, List Comprehensions & Dictionaries.
- Implement verifiable algorithms and architectures utilizing Python 3.10+, Pytest, Pandas, Requests.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Automated Data Processing & Web Scraping Pipeline**.

---

## 📚 Topics
1. **Python Data Types, List Comprehensions & Dictionaries**
2. **Object-Oriented Python & Magic Methods**
3. **File Handling, JSON & CSV Processing**
4. **Exception Handling & Unit Testing**
5. **Data Analysis with NumPy & Pandas**
6. **Web Scraping & Script Automation**
