# Course Syllabus: CS499 — Graduation Project

**Department:** Computer Science Department  
**Academic Term:** Y4S1-S2 (Year 4, Both Semesters)  
**Credit Hours:** 6 Credit Hours  
**Instruction Format:** Lectures (Sessions), Practical Laboratory Exercises, Graded Assignments  

---

## 📅 Weekly Topic Distribution
- **Week 1**: iLearn Smart Learning Platform: Full-Stack Architecture
- **Week 2**: Requirements Engineering (IEEE 830 SRS Specification)
- **Week 3**: Relational Database Design & Schema Architecture
- **Week 4**: Backend RESTful Microservices & API Gateway
- **Week 5**: Cross-Platform Mobile Application (Flutter/Android)
- **Week 6**: Responsive Web Application Frontend
- **Week 7**: AI Analytics, Smart Recommendation & Exam System
- **Week 8**: Security, Authentication & Role-Based Access Control
- **Week 9**: DevOps, Containerization & Cloud Deployment

---

## 📊 Assessment & Grading Matrix
- **Midterm Examination:** 20%
- **Practical Laboratory & Quizzes:** 20%
- **Assignments & Course Engineering Project:** 20%
- **Final Comprehensive Examination:** 40%
- **Total:** 100%
