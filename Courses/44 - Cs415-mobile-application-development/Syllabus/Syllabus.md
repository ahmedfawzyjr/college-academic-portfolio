# Course Syllabus: CS415 — Mobile Application Development

**Department:** Computer Science Department  
**Academic Term:** Y4S2 (Year 4, Semester 8)  
**Credit Hours:** 3 Credit Hours  
**Instruction Format:** Lectures (Sessions), Practical Laboratory Exercises, Graded Assignments  

---

## 📅 Weekly Topic Distribution
- **Week 1**: Mobile Development Paradigms: Native vs Cross-Platform
- **Week 2**: Dart Programming Language Fundamentals
- **Week 3**: Flutter Architecture: Widgets, State Management & Reactive UI
- **Week 4**: Navigation, Routing & Deep Linking
- **Week 5**: HTTP Networking, REST API Consumption & JSON Serialization
- **Week 6**: Local Storage (SQLite, SharedPreferences) & Offline Sync

---

## 📊 Assessment & Grading Matrix
- **Midterm Examination:** 20%
- **Practical Laboratory & Quizzes:** 20%
- **Assignments & Course Engineering Project:** 20%
- **Final Comprehensive Examination:** 40%
- **Total:** 100%
