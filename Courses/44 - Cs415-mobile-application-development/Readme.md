# CS415: Mobile Application Development (برمجة التطبيقات المحمولة (Android/Flutter))

**Course Code:** `CS415`  
**Academic Term:** Y4S2 (Year 4, Semester 8)  
**Credit Hours:** 3 Credit Hours  
**Curriculum Category:** Mobile  
**Instruction Type:** Compulsory  
**Department:** Department of Computer Science, Future Academy  

---

## 📌 Overview
Mobile Application Development is an integral component of the computer science curriculum, providing in-depth theoretical foundations and practical application in Mobile Development Paradigms: Native vs Cross-Platform, Dart Programming Language Fundamentals, Flutter Architecture: Widgets, State Management & Reactive UI. The course bridges fundamental concepts with engineering practice, culminating in a concrete software implementation: **Cross-Platform Smart Student Course & Schedule App**.

---

## 🔗 Prerequisites
- **Formal Prerequisites:** `CS212`, `CS313`
- **Recommended Foundations:** See detailed [Prerequisites Document](./overview/prerequisites.md).

---

## 🎯 Learning Objectives
- Master the theoretical formulations and mathematical foundations of Mobile Development Paradigms: Native vs Cross-Platform.
- Implement verifiable algorithms and architectures utilizing Flutter, Dart, Provider / Bloc, REST APIs.
- Analyze computational trade-offs, complexity limits, and reliability factors.
- Complete and test the practical course engineering project: **Cross-Platform Smart Student Course & Schedule App**.

---

## 📚 Topics
1. **Mobile Development Paradigms: Native vs Cross-Platform**
2. **Dart Programming Language Fundamentals**
3. **Flutter Architecture: Widgets, State Management & Reactive UI**
4. **Navigation, Routing & Deep Linking**
5. **HTTP Networking, REST API Consumption & JSON Serialization**
6. **Local Storage (SQLite, SharedPreferences) & Offline Sync**
